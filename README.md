# Portfolio

UI 设计方向个人作品集网站。单文件开发（HTML / CSS / JavaScript，无框架、无构建），部署在 GitHub Pages。

**🔗 在线预览：<https://e-ver1024.github.io/portfolio/>**

## 网站内容

- **首屏聚光灯** — 鼠标光斑混合模式交互，照亮英文标题
- **项目经历** — 扇形卡片，滚动/触屏滑动展开，收回时堆叠成一摞
- **技能证书** — HTML/CSS、JavaScript、WordPress 建站、AI 绘图、SEO 等
- **作品集** — Banner 与网页设计作品，点击可放大查看
- **学习笔记** — PS / Figma / 即时设计的学习记录

## 本地运行

无需安装任何依赖，直接用浏览器打开 `index.html` 即可（保持 `assets/` 文件夹在同目录）。

## 目录结构

```
personal-site/
├── index.html          # 整站（样式与脚本内嵌）
└── assets/             # 作品图片与简历 PDF
```
